- **System Overview**: `architecture/system_overview.md`

### 📅 [Planning](/docs/planning)
Project management, epics, and roadmaps.
- **Epics (Phase 1)**: `planning/phase_1_epics.md`

- **Workflows**: `planning/workflows.yaml`

### 📚 [Guides](/docs/guides)
