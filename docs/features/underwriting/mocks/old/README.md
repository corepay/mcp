# Sovereign Underwriting: Interactive Mockups

This directory contains high-fidelity interactive HTML mockups demonstrating the key interfaces of the **Sovereign Cognitive Platform**.

## 🖥️ Available Scenes

### 1. [Merchant & Underwriter Core](sovereign_underwriting.html)
**Filename**: `sovereign_underwriting.html`

*   **Merchant OLA**: The application intake form featuring the **Atlas Concierge** widget (proactive help, suggestions).
*   **Underwriter Dashboard**: The primary workspace for reviewing the **Sovereign Brief**, managing the "Amber Zone," and viewing Profit-Aware routing recommendations.

### 2. [Ops & Governance Console](playbook_and_boarding.html)
**Filename**: `playbook_and_boarding.html`

*   **Governance Engine**: The Markdown-based **Playbook Editor** and the **Playbook Concierge** simulator.
*   **Boarding Operations**: A real-time view of global processor health (Circuit Breakers) and background boarding statuses (Pending/Active/Failed).
*   **Forensic "Eye"**: A visual analysis screen demonstrating multimodal Deep Learning checks on storefronts and ID holograms.

### 3. [Underwriter Workspace (Deep Dive)](underwriter_workspace.html)
**Filename**: `underwriter_workspace.html`

*   **Application Detail**: A tabbed view for deep inspection of specific applications (Overview, Entities, Docs).
*   **Atlas Transcript**: The full, searchable history of the **"Healing"** chat between Atlas and the merchant.
*   **Context Graph**: A "Precedent Explorer" that surfaces similar historical applications to aid decision-making.

### 4. [Evidence Vault & Settings](evidence_vault.html)
**Filename**: `evidence_vault.html`

*   **Evidence Vault**: A forensic audit tool for inspecting raw JSON reports (KYB/KYC) and immutable document hashes.
*   **Vendor Settings**: Configuration panel for managing API keys, webhook secrets, and **Circuit Breaker** thresholds for ComplyCube and QorPay.

## 🎨 Design System
All mockups use the **"Noir"** design language:
*   **Dark Mode Native**: High-contrast, OLED-friendly blacks (`#0a0a0a`).
*   **Signal Colors**: Emerald (Green) for Sovereign/Clean, Amber for Cognitive/Warning, Crimson for Failures.
*   **Glassmorphism**: High-blur backdrops for floating panels and overlays.
