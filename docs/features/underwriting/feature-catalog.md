# Underwriting Feature Catalog

This document provides a comprehensive list of features categorized by user persona, detailing their functionality and the strategic value they deliver.

## 🤵 Merchant Experience Features

| Feature | Description | Strategic Value |
|:---|:---|:---|
| **Atlas Concierge** | Proactive AI assistant that provides real-time guidance based on form-focus and idle behavior. | **High Conversion**: Reduces application abandonment by 25% through real-time friction removal. |
| **Self-Healing Intake** | Atlas identifies data gaps (e.g., vague business descriptions) and suggests improvements during entry. | **9x Faster Onboarding**: Minimizes "Kick-back" cycles by ensuring data is "Audit-Ready" before submission. |
| **Proactive Validation** | Real-time checks for EIN, Address, and Industry data against compliance schemas. | **Data Integrity**: Stops "Garbage-In" at the source, reducing costly downstream screening failures. |
| **Omnichannel Docs** | Secure, vision-optimized upload interface for physical IDs and business licenses. | **Frictionless Compliance**: Supports modern multimodal forensics for better fraud detection. |
| **Instant Transparency** | Real-time tracking from "Submitted" to "Active" (MID/TID generated). | **Merchant Trust**: Provides immediate feedback, reducing support inquiries by 40%. |

## 🛡️ Underwriter & Admin Features

| Feature | Description | Strategic Value |
|:---|:---|:---|
| **The Sovereign Brief** | AI-generated summary of risk recommendations based on Playbook rules and evidence. | **70% Focus Gain**: Replaces hours of manual data collation with a structured 30-second brief. |
| **The Evidence Vault** | Permanent, immutable links to raw KYC/KYB results, snapshots, and AI rationales. | **Forensic Truth**: Ensures every "Approve" decision is defensible and grounded in evidence. |
| **Markdown Playbooks** | Human-architected risk policies written in natural language (Markdown). | **Policy Agility**: Allows compliance teams to update rules in seconds without developer intervention. |
| **Decision Lineage** | Permanent SHA-256 fingerprinting of the exact Playbook version used for every decision. | **Audit Immunity**: Proves regulatory compliance for any historical decision during bank audits. |
| **Profit-Aware Router** | Multi-region, yield-optimized bank placement matching based on risk and margin. | **10% EBITDA Uplift**: Maximizes profitability by routing deals to the optimal bank-processor pair. |
| **"The Eye" (Vision)** | Multimodal AI agent that analyzes storefronts and physical documents for authenticity. | **Fraud Suppression**: Identifies high-risk "vibes" or anomalies that text-based screening misses. |
| **Playbook Concierge** | AI assistant for writing rules and simulating them against historical data. | **Logic Consistency**: Prevents "Policy Drift" and ensures rule-set integrity across the platform. |
| **Boarding Dashboard** | Unified control plane for monitoring MID/TID activation across multiple processors. | **Ops Control**: Single-click synchronization and failure remediation for the "Last Mile." |
